# Expo Native Config Plugin & Bridgeless Integration

## Operating Principles
- Never modify files inside the `/ios` or `/android` root directories directly. These folders are ephemeral build artifacts generated by `npx expo prebuild`.
- All modifications to native properties (`Info.plist`, `AndroidManifest.xml`, `Podfile`, `build.gradle`) must be performed via plugins in `app.json` or custom configuration plugins inside `plugins/<name>.js`.

## Step-by-Step Procedure
### 1. Scaffold Config Plugin
When configuring native permissions, dependencies, or initialization hooks, create a new plugin in `plugins/<plugin-name>.js`:
```javascript
const { withInfoPlist, withAndroidManifest, createRunOncePlugin } = require('@expo/config-plugins');

const withCustomMobileBridge = (config, props = {}) => {
  // 1. Configure iOS Info.plist properties
  config = withInfoPlist(config, (config) => {
    config.modResults['NSCameraUsageDescription'] =
      props.cameraPermission || 'Allow access to camera for scanning.';
    return config;
  });

  // 2. Configure Android AndroidManifest.xml properties
  config = withAndroidManifest(config, (config) => {
    const mainApplication = config.modResults.manifest.application[0];
    // Safely add meta-data or attributes
    return config;
  });

  return config;
};

module.exports = createRunOncePlugin(withCustomMobileBridge, 'custom-mobile-bridge', '1.0.0');
```

### 2. Register Plugin in Project Manifest
Update `app.json` or `app.config.ts`:
```json
{
  "expo": {
    "plugins": [
      [
        "./plugins/custom-mobile-bridge.js",
        { "cameraPermission": "Camera access is required for real-time document capture." }
      ]
    ]
  }
}
```

### 3. Dry-Run and Verify Native Generation
Execute the prebuild generation check to ensure the plugin compiles clean platform files:
```bash
npx expo prebuild --clean --no-install
```
Inspect generated files and check exit status: `echo $?` must equal 0.
